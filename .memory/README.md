# .memory/ - 작업 기억

`MEMORY.md`(저장소 최상위)가 색인이고, 자세한 내용은 여기 둔다.
기억 파일은 관련 코드와 **같은 커밋**에 넣는다.

| 폴더 | 무엇을 | 규칙 |
|---|---|---|
| `active-issues/` | 알려진 버그, 낡은 문서, 아직 확인 안 된 것 - "믿기 전에 읽을 것" | 해결되면 항목을 지운다(히스토리는 git에). **파일당 150줄 이하** - 넘으면 정리가 먼저 |
| `roadmap/` | 다음에 할 일, 단계별 완료 조건, 숫자가 있는 사실(몇 줄, 몇 파일, 몇 개 통과) | 숫자에는 언제/무엇으로 쟀는지를 붙인다 |
| `sessions/` | `YYYY-MM-DD-주제.md` - 한 세션의 경위, 결정 이유, 틀렸던 가정 | 쓰고 나면 고치지 않는다(기록이므로). 정정은 새 파일에 |

폴더를 더 만들지 않는다. 같은 종류의 파일을 영역별로 쪼개지 않는다(쌍으로 늘어나면
관리 부채가 된다).
