## 결정/주의
- 새 브랜치를 `origin/main`에서 만들면 upstream이 `origin/main`으로 잡힌다 - 그대로 `git push`하면
  main으로 간다. `git branch --unset-upstream` 후 `git push -u origin claude/ui-fixes`로 올린다.
- 기본 성별 변경은 의도한 동작 변경이라 골든 9개(new_game_*, growth_*, combat_status_effects)가
  바뀌었다 - 귀검사 외 캐릭터의 "성별" m->f와 "초상화" 끝자리만(60줄).
- 이름 6자 테스트에 같은 이름 둘을 넣지 않았다 - 이름 중복은 B4(장비 섞임) 버그라 테스트가
  버그에 기대게 된다.
- [뒤로] 키: 버튼에 `뒤로키_버튼()` 표시 -> `뒤로키_처리`가 맨 위 팝업/현재 화면에서 표시된 버튼을
  누른다. 표시 없는 팝업은 `auto_dismiss`일 때만 닫는다(능력치 배분, 전투 반응은 그대로).
  `Window`는 main.py `build()` 안에서 import한다(모듈 import 시점에 창을 만들지 않게).
