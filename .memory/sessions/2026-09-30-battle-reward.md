# 2026-09-30 전투 보상 3칸 선택 (브랜치 claude/gifted-ramanujan-y6xska, 자동전투 커밋 위)

사용자 요청: 승리 팝업의 [확인] 위에 [전투 보상] - 받기 전엔 [확인] 비활성화. 누르면 전투한 몬스터들의 드랍
아이템 목록에서 3개가 나오고 1개를 골라 습득. 큰 박스 안에 왼쪽/중앙/오른쪽 세 박스.
물어서 정한 것:
- 후보는 **몬스터마다** 넣는다(같은 드랍풀 몬스터 둘이면 같은 아이템이 두 번) -> 같은 아이템이 여러 칸에 나올 수 있다.
- 가중치는 **드랍표 안의 드랍비율/드랍확률만**(확정 보상이라 몬스터 쪽 발동확률은 안 봄).
- 뽑힌 후보 항목은 다시 안 뽑는다 -> 후보가 0~2개면 남는 칸은 **빈칸**.
- 박스를 누르고 [선택]. 박스에는 아이템 이름만. 중앙 박스 아래 **[포기하기(10골드)]** = 고르지 않고 10골드를 받음.
  닫기 버튼은 없다(포기하기가 대신).
- 패배/도망에는 보상 없음. 무작위 드랍(전리품)은 그대로 따로 준다.

## 구현
- `loot_system.보상_후보목록`(아이템조건은 맞는 아이템 전부로 풀고 가중치를 나눔), `보상_뽑기`.
- `gameflow._전투_보상_준비`(전투_결과_정리 승리 시, 카탈로그에 없는 이름 제외) -> `게임상태["전투_보상"]`,
  `전투_보상_대기중/칸/받기/포기`, `보상_포기_골드 = 10`.
- 화면 `_전투보상팝업`: `_테두리박스`를 재사용(고른 박스는 테두리를 굵게). 뒤로 키는 이 팝업에서 아무것도 안 한다.

## 골든
`scenario_campaign.json`만 - 보상 뽑기가 random 흐름을 바꿔 무작위 인카운트 기록만 달라짐(나머지 동일 비교 확인).

## 검증
게이트 통과, ui_smoke: 승리 -> [확인] 잠김 -> [전투 보상] -> 박스 누르고 [선택](소지품 +1) / 빈칸 3개에서 포기(+10골드)
-> [확인] 풀림. 스크린샷으로 레이아웃 확인.
