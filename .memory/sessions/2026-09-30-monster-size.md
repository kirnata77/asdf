대형 1.25배로. 대형은 옆 칸을 침범해도 된다. 분류: 고블린/루가루 전부 소형, 좀비/인간형 타우 중형,
타우킹 샤우타/타우 비스트 대형. 물어서 정한 것: 인간(케라하/비노슈)은 중형, **발바닥(칸 바닥) 기준**,
겹치면 **대형이 뒤**, 같은 크기끼리는 왼쪽이 앞.

## 구현
- 데이터 `"크기"`(28종 전부, 없으면 중형 - monster_format.py "몬스터 크기").
- `gameflow.몬스터_크기_배율`, `적_크기`/`적_표시_배율`(모르는 값 ValueError), `적_그리기_순서`(대형 먼저,
  같은 배율은 오른쪽부터 - 먼저 그린 것이 뒤).
- 화면: 1배 = 예전처럼 비율 유지로 칸에 꽉 맞춘 크기. 칸(테두리)은 그대로 두고 그림은 `적그래픽행.canvas.after`에
  Rectangle로 직접 그린다(칸 안 Image 위젯이면 다음 칸이 위에 그려져 넘친 부분이 가려진다). 칸 pos/size가 바뀌면
  Clock 0초로 다시 그린다. 텍스처는 경로별 캐시, mag_filter nearest.
- 대형은 위로 솟아 적 이름표 칸 아래쪽을 조금 가린다(발바닥 기준 선택의 결과).
