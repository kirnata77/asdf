# 2026-09-30 거너 스킬 "라이징 샷" 추가

## 요청
`job_skill_030f_gunner.py` 마하킥 위에 "라이징 샷": 공격스킬, 타입 스킬, 레벨습득 1, 일반행동, 적단일, 무,
보정공격력x1, 보정명중률, 보너스 0, 공격횟수 1, 일반공격취급 True, 명중 시 DC 10+차수 건강굴림 실패하면
"공중에 뜸" 1턴. MP는 물어서 5로 정했다.

## 한 것
- 스킬 데이터: 효과는 기존 `"상태이상"` 양식 그대로(`"이름": "공중에뜸"` - status_effects.py 이름에 맞춰 띄어쓰기 없음,
  `"난이도": "10+차수"` - formula가 시전자 차수로 평가). 전투 로직 변경 없이 동작한다.
- **"습득레벨"은 실제 습득에 쓰이지 않는다** - 스킬은 job_level 표의 "스킬획득" 항목에 적힌 것만 배우고, 레벨 1은
  특성만 주는 항목이었다. 사용자와 정해 레벨 1 항목에 선택 키 `"시작스킬"`을 추가하고
  `character_creation_system._시작_스킬_설정`이 생성 때 보유스킬에 넣는다(job_level_format.py에 문서화).
- 이전 세이브의 거너에게는 주지 않는다(질문할 때 알렸고 사용자가 이 선택지를 골랐다) - known-bugs에 기록.
