# 2026-09-30 B1 도망 규칙 (브랜치 claude/gifted-ramanujan-y6xska)

사용자 요청: "도망을 실패하면 자동으로 턴 넘기기가 눌리게". 계획을 보여 주고 물은 뒤 사용자가 정한 규칙:

- **판정 실패 -> 현재 캐릭터의 턴 종료** (`gameflow.아군_도망시도`가 `턴_넘기기`를 부른다 - 이어지는
  몬스터 턴도 진행). 한 턴에 무한 재시도(B1)가 없어졌다.
- **민첩판정은 현재 턴의 캐릭터가 굴린다.** 전에는 파티에서 민첩이 가장 높은 캐릭터(`파티_최고능력치_참가자`)가
  대표로 굴렸다. 그 함수는 이제 테스트에서만 쓴다(지우지 않음).
- **파티 중 한 명이라도 구속("도망불가" 효과)이면 도망 불가** - 판정도 턴 변화도 없다. 전에는 대표 한 명만
  봤다. 화면은 [도망]을 누르면 확인 팝업 대신 "도망 칠 수 없습니다. / 대상 : 이름 / 상태이상 : 구속 / [확인]"
  팝업을 띄운다(`gameflow.도망_막는_상태이상`, 여러 명이면 대상/상태이상 줄을 사람마다 반복).
- `전투이탈_시도` 주석을 코드에 맞춰 "같거나 높으면 성공"으로.
- 아군 차례가 아닐 때 도망을 부르면 ValueError(로직 방어).

## 검증
게이트 294개 통과, 골든 불변(기존 도망 테스트는 골든을 안 쓴다). ui_smoke에 구속 팝업/실패 후 턴 종료
단계를 넣고 Xvfb로 돌려 스크린샷으로 팝업 모양을 확인했다.

## 틀렸던 가정
- 실패 테스트를 처음에 "사이에 몬스터 턴이 돌았다(로그가 늘었다)"로 짰는데, 귀검사 다음이 바로 아군이라
  틀렸다. [턴 넘기기]를 직접 누른 복제본과 비교하는 방식으로 바꿨다.
- 그 비교가 전체 실행에서만 어긋났다 - 몬스터 대상 고르기가 `randint` 말고 다른 random 함수를 써서,
  `randint`만 고정하면 두 실행의 random 흐름이 다르다. 두 실행 앞에 같은 `random.seed`를 넣었다.
