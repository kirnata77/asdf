# 2026-09-30 귀참/넨탄/매직미사일을 레벨 1 스킬로

## 요청
"귀참, 넨타, 매직미사일도 습득레벨을 1로 만들고, 데이터 파일에서 순서를 맨 위로 올려줘, 습득레벨 순서대로 배우게."
"넨타"는 격투가 `넨탄`으로 봤다. 같은 날 라이징 샷(`sessions/2026-09-30-rising-shot.md`)의 후속이라 같은 브랜치/PR.

## 한 것 (데이터만)
- job_skill 파일 3개: 해당 스킬을 `스킬목록` 맨 위로 옮기고 `"습득레벨": 1`. 마법사는 구역 주석이 있어 맨 위에
  "레벨 1 스킬" 구역을 새로 달았다(매직미사일은 원래 "기타 스킬" 구역).
- job_level 파일 3개: 레벨 1 `"시작스킬"`에 넣고, 레벨 3 "스킬획득" 목록에서 뺐다(두 번 배우지 않게).
  실제 습득 순서 = 보유스킬 순서 = 레벨 1 시작스킬 -> 레벨 3 목록.

## 골든 (UPDATE_GOLDEN=1, 의도한 변경) - 8개, 스킬 목록 외 값은 그대로
- `new_game_귀검사/격투가/마법사`: 레벨 1부터 보유스킬과 스킬목록(화면용)에 해당 스킬.
- `growth_` 같은 3직업: 레벨 1~2에 스킬이 생기고, 레벨 3 이후는 보유스킬 순서만 바뀜(해당 스킬이 맨 앞).
- `combat_버프`, `combat_디버프`: 참가자 보유스킬 순서만 바뀜.
- `보유스킬`/`스킬목록` 키를 빼고 비교해 나머지 값이 같음을 스크립트로 확인했다.
