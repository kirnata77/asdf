# 2026-09-30 치트용 마법석 (브랜치 claude/gifted-ramanujan-y6xska, B1 커밋 위)

사용자 요청: 마법석 "치트용 마법석" - 레어도 "치트", 티어 99, 착용하면 던전 무작위 인카운트 0, 이벤트 전투는 가능.
물어서 정한 것: 파티원 중 한 명이라도 착용하면 / 모든 상점(엘븐가드, 헨돈마이어)에서 0골드 /
착용 중엔 걸음수를 쌓지 않음 / 능력치 없음 / 브랜치는 이 작업 뒤 사용자가 정리.

## 구현
- 효과는 이름이 아니라 데이터 키: 아이템 `"특수효과": {"인카운트없음": True}`(양식 설명은 마법석 파일 머리 주석).
- `gameflow.파티_인카운트없음` -> `map_system.이동_시도(..., 인카운트없음=)`가 걸음수 증가와
  `인카운트_판정`을 둘 다 건너뛴다. 보스 등은 `오브젝트_상호작용` 경로라 영향 없음.
- 쓰러진 파티원이 착용해도 효과가 있다(장비 기준 - 따로 묻지 않고 정함).

## 검증
게이트 295개 통과, 골든 불변. 카탈로그 개수 테스트의 마법석 1 -> 2. 새 시나리오 테스트: 모든 마을 판매,
0골드 구매, 착용 후 200번 이동에 전투 없음 + 걸음수 0, 세이브 왕복 뒤에도 유지, 보스 전투 열림, 벗으면 인카운트 복귀.
화면 코드는 안 바꿨다(상점/장비 화면은 기존 목록을 그대로 그린다) - ui_smoke는 안 돌림.
