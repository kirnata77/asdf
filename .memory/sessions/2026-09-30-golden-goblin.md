# 2026-09-30 황금 고블린 데이터 (브랜치 claude/gifted-ramanujan-y6xska, #14 병합 뒤 main에서 다시 만듦)

사용자 요청과, 물어서 정한 것:
- 기본 스탯은 고블린과 똑같이. 특성 "황금도둑": **모든 능력치 +4**, **자기 턴이 5번 끝나면 도망**(처치로 치지 않음).
- 골드 **레벨×100**. 드랍표 "황금고블린군" **100%**(반드시 하나) - 차수별, **1차수 = 언커먼 장비 전체**.
- 등장: 인카운트가 나면 **1% 확률로 등장 적 중 무작위 한 마리가 황금 고블린으로 바뀜**(항상 한 마리, 다른 적과
  함께 나올 수 있음). 처음 제안한 "황금 고블린 그룹 +1% 가중치"는 사용자가 이 방식으로 바꿨다.
- 황금 고블린 외 적을 잡았으면 승리 + 잡은 적 전리품만. 적이 모두 도망치면 **"적이 도망쳤다!"**만(다른 도망
  몬스터가 추가될 수 있어 황금 고블린 전용 문구로 하지 않음).

## 구현
- 데이터: `monster_race_goblin.py` "황금 고블린"(고블린 블록 복사 - 다른 것은 몬스터명/이미지/출현장소/특성/
  획득골드/드랍표뿐), `monster_ability.py` "황금도둑"(`{"변동대상": "능력치", "변동값": 4}` + `"도망턴": 5`),
  `monster_drop.py` "황금고블린군"(`"타입": "차수별"`, `"차수표"`, 아이템조건 카테고리 "장비").
- 엔진: `traits.능력치특성_반영`(전투_시작이 참가자 생성 전에 원본 사본에 더함 - HP/AC/속도 수식이 올라간 능력치로
  계산), `traits._도망_검사`(턴 종료 마지막에 `끝난턴수`를 세고 도망: 생존 False + 도망 True + 로그 "도망쳤다!"),
  `다음_턴`은 방금 도망쳐 전투가 끝나면 다음 턴을 시작하지 않는다, `전투_종료_판정`에 "적도망".
- 전리품: `loot_system.골드_굴림`이 수식(몬스터 레벨/차수)을 읽고, 드랍표 "차수별"을 몬스터 차수로 고른다.
  gameflow 전리품/전투 보상은 `도망` 참가자를 뺀다. `전투_종료_문구("적도망")` = ["적이 도망쳤다!"].
- 조우: `map_system.인카운트_교체몬스터/인카운트_교체확률`(0.01) - 인카운트_판정 끝에서 한 마리 교체.
- 화면: 도망친 적은 이름표 "(도망)", 그림을 그리지 않는다.

## 골든
- `combat_monsters_monster_race_goblin.json`: "황금 고블린" 키만 추가(기존 키 값 동일 확인).
- `scenario_campaign.json`: 인카운트마다 교체 판정을 굴려 random 흐름이 달라져 무작위 인카운트 기록만 바뀜(그 외
  동일 확인). 캠페인에 황금 고블린은 안 나왔다.

도망 = 승리/고블린 전리품만, 잡으면 300골드 + 언커먼 1개 + 보상 3칸 언커먼, 인카운트 교체 1%). ui_smoke에 도망
