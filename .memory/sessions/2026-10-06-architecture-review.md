# 2026-10-06 구조 점검과 N0~N7

사용자가 구조/아키텍처 점검 보고서를 요청 -> 목차 합의 -> 상세 계획 합의 -> "다음 로드맵으로 전부 진행".

- 보고서: `docs/architecture_review.md`(10절에 처리 결과). 로드맵: `.memory/roadmap/refactor.md`.
- **틀렸던 가정:** (1) 프로파일에서 크게 보인 특성 재계산은 시나리오 테스트 약 8~10%뿐이고 전투 한 판은 7ms라 캐시는 안 만들었다.
  (2) 로컬 DB는 효율을 올리지 않는다(데이터가 작고 조회가 이름 조회). (3) 처음엔 `기본_마을목록` 비용과 세이브 요약을 성능 문제로 의심했으나 0.3ms.
  (4) combat 순환은 도메인 재귀라 다 못 끊는다(4개 모듈 묶음은 남김). (5) 커밋 메시지에 복잡도 수치를 재지 않고 적었다가 직접 재서 정정했다.
- **발견:** 잘린 세이브 하나가 메인 메뉴를 막음(수정), 몬스터 7종의 `종족:루가루/인간` 특성 정의 누락(known-bugs), 테스트 하나가 실제 버프 목록을 오염(수정).
- 결과 요약은 보고서 10절. 미확인: 실기기 세이브 유지, GitHub Actions ui-smoke 잡.
