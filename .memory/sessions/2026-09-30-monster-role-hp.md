# 2026-09-30 몬스터 역할군 HP/AC (브랜치 ccr-63aa21d8-drxhsv, main #17 뒤에서 만듦)

사용자 요청: 루가루/쿠로가루/펜릴 딜러, 시로가루 메이지, 정원사 랄 탱커로 HP가 계산되게. 이어서 "다른 몬스터도 다".
루가루 5종은 역할군이 이미 맞게 들어가 있었고 최대HP만 "미정"이었다(AC는 이미 공식).
역할군이 없던 고블린 9종은 사용자에게 물어서 정함: 메이지 = 힐가브/시가브/플래그 힐가브/플래그 시가브,
딜러 = 전격의 키놀/고블린 투척십장/프라그, 탱커 = 고블린 십장/벙커워커. AC도 역할군 공식으로(사용자 답).

## 변경
- 23종의 "최대HP"/"AC"를 monster_format.py 공식 문자열로(루가루 5 HP, 타우 4 HP+AC, 고블린 9 역할군+HP+AC).
  나머지 6종은 이미 공식과 같았다(29종 전부 일치를 테스트가 검사).
- 골든: 몬스터 전수 3개(goblin/tau/lugaru)만 바뀜. 전수 조건(레벨 6)에서 예: 루가루 HP 1 -> 30,
  시로가루 1 -> 18, 정원사 랄 1 -> 48, 힐가브 0 -> 17, 타우 가드 19 -> 84. human/zombie 골든은 그대로.
- test_combat_rules.py: 전 몬스터 역할군·공식 일치 + 레벨 3 기본최대HP 값 8건(예: 루가루 15).

## 2단계: 데이터는 None, 전투 때 역할군 공식표에서
사용자 요청: 모든 몬스터 최대HP/AC를 None으로 두고 역할군 공식으로 전투 때 불러오기. 물어서 정한 것:
**예외 몬스터 없음**(데이터에 값을 적어도 쓰지 않는다), **역할군이 없거나 모르는 값이면 HP 1 / AC 10**.
- `monster_format.py`에 `역할군공식` 딕셔너리(주석으로만 있던 표를 데이터로). 새 파일이 아니라 file_path 변경 없음.
- `participants.몬스터_역할군_수식(원본, "최대HP"|"AC")` - `_적_참가자_생성`과 `stats.최종AC`가 이것만 쓴다.
- 골든: 몬스터 전수는 그대로(계산값 불변). 효과 전수 3개(상태이상/버프/디버프)는 대상 타우 아미의
  원본 데이터 사본이 기록돼 있어 `"최대HP"`/`"AC"` 문자열 -> null 102쌍만 바뀜(HP/AC/피해 값은 같음).
- 테스트: 29종 None+역할군, 수식 조회(예외 무시, 역할군 없음/"미정"/리스트 -> None), 역할군 없으면 HP 1·AC 10.
