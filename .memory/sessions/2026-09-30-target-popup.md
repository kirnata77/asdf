## 요청

(전에는 [일반공격]/스킬을 고른 뒤 화면 위쪽 적 상태 칸을 눌러 대상을 골랐다.)

## 한 것 (`game/screens/screens_battle.py`만, 로직/gameflow 변경 없음)
- `_대상선택팝업`: 살아 있는 적 버튼(`이름 (HP n)`) + [취소](`뒤로키_버튼`, auto_dismiss 없음).
  쓰러진/도망친 적은 목록에 없다. 같은 이름은 전투가 이미 `고블린 A/B`로 구분한다.
- [일반공격], 적단일, 적3체(제목 "중심 대상"), 적반복지정 스킬이 이 팝업을 연다. 고르면 기존
  `_대상_선택`으로 넘긴다 - 실행 경로는 전과 같다. [취소]는 `선택모드`를 비우고 안내 문구를 턴 문구로 되돌린다.
- 적반복지정: 한 번 고를 때마다(거부돼도) 팝업을 다시 연다, 제목에 `(n/횟수)`. 도중 [취소]는 스킬 전체 취소
  (자원 소모 없음 - 실행 전이므로). 거부 조건은 `_반복지정_거부사유`로 뺐다(은신/중복불가/대상당피격제한, 문구 그대로).
- 적 상태 칸의 터치 바인딩은 뺐다. 아군단일(치유 등)은 요청 범위 밖이라 그대로 아군 칸 터치.
