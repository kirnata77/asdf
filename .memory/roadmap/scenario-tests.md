# 풀 시나리오 테스트 계획

점검 2026-10-06(`main` e40ada6): 462개 통과, 풀 시나리오 없음 - 현황은 [`docs/scenarios.md`](../../docs/scenarios.md).
전투를 실제로 굴리는 건 레벨 1 일반공격 보스전/인카운트 1회뿐이라, 스킬/장비/성장/보상이 **전투를
거쳐 이어지는지**는 어디서도 검사하지 않는다. 캠페인 테스트는 전투를 강제 승리로 건너뛴다.

## 설계

- 시나리오 = 파티(직업/무기/방어구) + 시드 + 단계 목록. 진행은 `gameflow` 창구만, 전투는 실제로 굴림.
- 새 도우미 `tests/scenario.py`: 전투 정책(일반공격만 / 스킬 우선 / 포션 사용), 전투 후 보상 수령,
  성장 정책(`support.성장` 재사용), 스냅샷(종료, 라운드, 생존, 소지품, 골드, 진행도, 레벨).
- 검사는 **요약 골든 + 불변식**(HP 0 이하는 쓰러짐, 보상은 소지품에 들어감, 레벨은 플레이어레벨 이하 등).
  전체 로그 골든은 쓰지 않는다. 시드를 고정하고 `random` 전역 상태를 시나리오마다 초기화.
- 마커 `@pytest.mark.scenario("S1")`(pyproject에 등록) + `docs/scenarios.md` 표와 ID 대조 테스트(P0 완료).

## 단계 (위에서부터, 한 단계 = 브랜치/PR 하나)

- ~~P0 기반~~ **완료 2026-10-06** - 마커 등록(`--strict-markers`), `tools/scenario_registry.py` + `test_repo_hygiene`의 장부 대조 테스트 3개, `docs/scenarios.md` 표(S1~S6 전부 `계획`). 도우미 `tests/scenario.py`(전투 정책/스냅샷)는 쓰는 P1에서 만든다(안 쓰는 코드를 먼저 넣지 않는다).
- ~~P1 S1 첫 던전 실전~~ **완료 2026-10-06** - `tests/scenario.py`(실전/인카운트까지_걷기/보상_수령) + `test_scenario_s1.py`. 실전 3회+보스, 보상/장비/판매/세이브 왕복, 요약 골든 1개. 변이 확인: HP 되돌려쓰기 제거와 전리품 골드 미지급을 각각 잡는다. 한계는 docs/scenarios.md.
- **P2 S2 스킬 실전** - 직업별(귀검사/격투가/거너/마법사/프리스트) 스킬 우선 정책으로 고블린/루가루/타우
  종족과 싸운다. 기능: 스킬 소모와 쿨다운, MP/행동자원, 버프/상태이상이 실전에서 걸리고 풀림.
- **P3 S3 성장 실전** - 보스 처치로 플레이어레벨 상승 -> 레벨업(마스터리/퍽) -> 전직 -> 새 무기로 다음
  던전 실전. 5직업. 기능: 레벨업/전직/무기 숙련/특성 효과가 전투 수치에 반영되는지(레벨 6 특성 포함).
- **P4 S4 무기 x 몬스터 행렬** - 무기 종류(소검/도/둔기/대검/광검/권투글러브/리볼버 등) x 몬스터 종족(고블린/
  루가루/타우/좀비/인간). 같은 시드에서 속성/무기 특성(기절, 치명타 범위 등) 요약 단언.
- **P5 S5 패배 복귀** - 실제로 지는 파티(레벨 부족) -> 패배 처리 -> 휴식 -> 재도전. 도망 성공/실패 포함.
- **P6 S6 캠페인 실전** - 던전 10개를 실제 전투로, 성장 정책 포함, 시드 여러 개. 밸런스 스모크이므로
  "클리어 가능 + 시간 한도(전체 30초 이내)"만 단언하고 값은 박지 않는다. 느리면 CI에서 제외 표시.
- 각 단계: 시나리오 문서 행 추가, 작업 중 발견한 버그는 `active-issues/`에 기록하고 따로 고친다.

## 열린 문제

- 자동전투/도우미의 스킬 사용 정책은 아직 없다(`support.자동_전투`는 일반공격만) - P2에서 만든다.
- 실전이라 소요 시간이 늘어난다. 현재 전체 15.5초, 시나리오 합계 한도를 정해 둔다(안: +20초).
- 버프포션/자동전투 포션/엘레멘탈 번은 미구현이라 시나리오 범위 밖(구현 시 해당 시나리오에 추가).
