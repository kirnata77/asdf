# 풀 시나리오 테스트 계획

점검 2026-10-06(`main` e40ada6): 462개 통과, 풀 시나리오 없음 - 현황은 [`docs/scenarios.md`](../../docs/scenarios.md).
전투를 실제로 굴리는 건 레벨 1 일반공격 보스전/인카운트 1회뿐이라, 스킬/장비/성장/보상이 **전투를
거쳐 이어지는지**는 어디서도 검사하지 않는다. 캠페인 테스트는 전투를 강제 승리로 건너뛴다.

## 설계

- 시나리오 = 파티(직업/무기/방어구) + 시드 + 단계 목록. 진행은 `gameflow` 창구만, 전투는 실제로 굴림.
- 새 도우미 `tests/scenario.py`: 전투 정책(일반공격만 / 스킬 우선 / 포션 사용), 전투 후 보상 수령,
  성장 정책(`support.성장` 재사용), 스냅샷(종료, 라운드, 생존, 소지품, 골드, 진행도, 레벨).
- 검사는 **요약 골든 + 불변식**(HP 0 이하는 쓰러짐, 보상은 소지품에 들어감, 레벨은 플레이어레벨 이하 등).
  전체 로그 골든은 쓰지 않는다. 시드를 고정하고 `random` 전역 상태를 시나리오마다 초기화.
- 마커 `@pytest.mark.scenario("S1")`(pyproject에 등록) + `docs/scenarios.md` 표와 ID 대조 테스트(P0 완료).
