## 7. 비교로 본 평가

- **가장 큰 이득:** 세이브 안정성(재현 가능한 데이터 손실/진입 불가 2건 해결), 구조 가시성(만능 파일 해체, 순환/밑줄 규칙을 테스트로 고정), 안전망(테스트 +105, 골든 불변).
- **측정으로 얻은 보너스:** 수식 평가 약 2배, `eval` 0개.
- **하지 않은 것의 근거는 측정이었다:** 캐시(8%), DB(이득 없음), 팝업 틀/크래시 로그(위험 대비 근거 부족).
- **남은 큰 일:** `skill_system` 추가 분해, 화면 코드 정리, combat 순환의 최종 해소, 데이터 기본값 도우미 - 모두 우선순위 낮음~중간이고 사용자/유지보수자 결정이 필요한 콘텐츠 항목(종족 특성 등)이 먼저다.

## 8. 측정 방법과 한계

- **구조 지표:** `ast`로 `game/`, `gameflow.py`, `main.py`, `tools/`를 순회(데이터/테스트 함수 제외). 복잡도는 분기 + 불리언 연산 수 + 1의 추정이다(`radon`과 다를 수 있음). 같은 스크립트를 두 커밋의 작업 트리에서 실행했다.
- **테스트/커버리지/시간:** 두 커밋에서 `python tools/check.py`를 실행했다(같은 컨테이너, 1회 측정이라 시간은 오차 있음).
- **동작 재현:** 같은 스크립트로 세이브 손상/쓰기 실패/전투 시간/수식 시간을 두 커밋에서 실행했다(전투/수식 시간은 이 환경의 값이며 실기기가 아니다).
