# 시나리오 목록 (풀 시나리오 테스트 관리 문서)

규칙은 [`CLAUDE.md`](../CLAUDE.md) "풀 시나리오 테스트". 이 문서는 **어떤 시나리오가 어떤 기능을, 어떤
캐릭터/무기/몬스터로 검사하는지**의 장부다. 시나리오를 추가/변경하면 같은 커밋에서 이 표를 고친다.

"풀"의 기준: 전투를 `강제_승리`로 건너뛰지 않고 실제로 굴리며, `gameflow` 창구로 이어서 진행한다.

## 시나리오

[`.memory/roadmap/scenario-tests.md`](../.memory/roadmap/scenario-tests.md)의 계획 단계와 같은 순서다.
**상태**는 `계획`(아직 테스트 없음) / `구현`(테스트가 있고 `@pytest.mark.scenario("ID")`가 달림).
**테스트** 칸은 `파일::함수`를 쉼표로 적는다. 이 표와 테스트의 마커는 `tests/test_repo_hygiene.py`가 대조한다
(`tools/scenario_registry.py`) - 어긋나면 게이트가 실패한다.

## 시나리오별 한계 (알고 쓴다)

- **S1**: 전투는 `[자동전투]`와 같은 호출(`gf.자동전투_한_턴`, 무작위 일반공격)이라 스킬/포션/도망은 안 쓴다(S2/S5).
  상점/장비 호출은 위치 검사가 없어 마을로 걸어가지 않고 던전 상태에서 부른다(마을 이동은 S6).
  불러오기는 던전 위치를 저장하지 않으므로 다시 진입한다. 시드 1에서 모두 이기는 것을 확인한 고정 시드다 -
  전투 규칙이 바뀌면 골든이 바뀌고 이기지 못할 수도 있다(그땐 시드를 고르고 이유를 커밋에 적는다).
- **S2**: 파티는 `support.성장`으로 레벨 5까지 결정적으로 키우고 `[스킬습득]`으로 스킬을 전부 배운 것이다(성장 자체는 S3).
  전투 사이는 `gf.휴식`(마을 휴식)으로 MP를 채운다. 정책은 해제 -> 회복 -> 버프 -> 자원 -> 소환 -> 공격 순으로 쓰고,
  버프는 지속이 끝나야 다시 걸며, `적반복지정` 스킬(대상을 따로 고르는 팝업이 필요한 것)은 쓰지 않는다. 쓸 스킬이 없거나
  MP가 모자라면 일반공격. 머크우드 인카운트의 몬스터는 무작위라 시드마다 루가루/고블린이 다르다(보스는 항상 타우).
  "버프가 풀리는가"는 지속턴이 다시 걸지 않는 한 늘지 않고 0 이하로 남지 않는다는 것과 사라진 효과 수(골든의 `만료된_효과`)로 본다.
  `휴식당횟수` 제한이 바닥나는 경로, 상태이상 내성/면역, 도망은 안 거친다. 레벨 1~4와 전직 스킬은 S3에서 본다.
